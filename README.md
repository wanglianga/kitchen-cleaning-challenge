# 微缩厨房清洁挑战 🧹

一款使用 Phaser 3 制作的休闲清洁小游戏。玩家操控小小清洁员在巨大的厨房台面上穿梭，完成各种限时清洁任务。

## 原始需求

> 请用 Phaser 制作微缩厨房清洁挑战游戏，玩家操控小小清洁员在巨大的厨房台面、锅具、泡沫、水流、油污和餐具之间移动，完成限时清洁任务。角色可以滑行、喷清洁剂、推海绵、躲避热锅、借水流冲刺和把碎屑扫进收集口；每关目标包括擦掉顽固污渍、关闭滴水龙头、整理餐具和保护易碎杯盘。画面要让污渍材质、危险节奏和可互动道具一眼可见，操作轻快，失误后能快速回到清洁路线。
> 扩展污渍材质差异：油渍需要清洁剂软化，糖浆会黏住角色，面粉遇水会扩大，水渍可以滑行加速，不同污渍组合会改变玩家先清哪里、带什么工具和如何规划路线。 
> 扩展热锅与蒸汽节奏：灶台上的锅会周期性喷汽、锅盖可被推动形成临时屏障，玩家能冒险穿过节省时间，也能绕路保证连击不断；被烫到会掉落手上的清洁道具。

## 游戏特色

- 🎮 **多种清洁手段**：喷清洁剂、滑行擦拭、推动海绵清洁
- 🔥 **危险元素**：躲避滚烫的热锅，小心不要被烫到
- 💧 **水流加速**：借助水流冲刺，快速穿梭厨房
- 🧽 **可交互道具**：推动海绵、关闭滴水的水龙头
- 🍽️ **易碎物品**：滑行时注意不要打碎杯盘
- 🍞 **收集碎屑**：把食物碎屑扫进收集口获得分数
- 🏆 **关卡系统**：无限关卡，难度递增

## 启动方式

### 前置要求

- 现代浏览器（Chrome、Firefox、Edge 等）
- 或者 Docker / Docker Compose

### 方式一：直接打开（最简单）

直接用浏览器打开 `index.html` 文件即可开始游戏。

### 方式二：本地静态服务器

如果需要通过 HTTP 方式访问，可以使用任意静态文件服务器。

使用 Python：

```bash
python -m http.server 8080
```

使用 Node.js 的 http-server：

```bash
npx http-server -p 8080
```

访问地址：http://localhost:8088

### 方式三：Docker 一键启动（推荐）

#### 启动命令

```bash
docker compose up --build
```

后台运行：

```bash
docker compose up --build -d
```

停止服务：

```bash
docker compose down
```

访问地址：http://localhost:8088

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动清洁员 |
| 空格键 | 喷射清洁剂（手持清洁剂时冷却-50%） |
| Shift | 滑行（可擦除污渍，手持海绵时伤害+100%） |
| E | 交互（关闭水龙头、拾取掉落道具、拾取场景海绵） |
| Q | 放下当前手持道具 |
| 回车键 | 开始游戏 / 重新开始 |

### 手持道具系统

| 道具 | 效果 | 获取方式 |
|------|------|---------|
| 🧽 **海绵** | 滑行清洁效果 +100% | 场景中按 E 拾取，或拾取掉落的海绵 |
| 💧 **清洁剂** | 喷雾冷却 -50%，可软化油渍 | 游戏初始自带，或拾取掉落的清洁剂 |

**规则说明：**
- 玩家始终手持一个道具（初始为清洁剂）
- 按 Q 可主动放下道具
- 被热锅烫到或被蒸汽烫到，**只会掉落当前手持的道具**
- 拾取新道具时，如果当前手持道具，会先放下原道具再拾取新的
- 掉落的道具有12秒存在时间，超时消失

## 游戏目标

每关需要完成以下目标才能进入下一关：

1. ✅ 擦掉所有污渍（包括顽固污渍）
2. ✅ 收集所有食物碎屑到收集口
3. ✅ 关闭所有滴水的水龙头

## 得分规则

- 普通污渍：+10 分
- 顽固污渍：+30 分
- 收集碎屑：+5 分
- 关闭水龙头：+25 分 + 5秒时间
- 完成关卡：+100 分 + 30秒时间
- 碰到热锅：-5秒时间
- 打碎杯盘：-8秒时间 -20分
